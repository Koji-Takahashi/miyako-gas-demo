# みやこ都市ガス 経営ダッシュボード（デモ）

講演「優秀な新入社員の使い方 〜生成AIと育てる現場の力、次の50年を切り拓く企業変革（AX）〜」の場面3（データアナリスト）で使うデモページです。

- スマホで見ることを前提にした1ファイルのページです（外部のライブラリやフォントは読み込みません）。
- 会社名・地区名・数値はすべて講演デモ用の架空データです。実在の会社・地域とは関係ありません。

## reform/（リフォーム完成イメージ・デモ）

場面4（システムエンジニア）で使うデモアプリです。

- STEP 1：その場で写真を撮る（またはファイルから選ぶ）。お客様宅の図面（DXF。キッチン・浴室のどちらでも、両方同時でも可）と会社の価格表（Excel）もアプリに読み込む
- STEP 2：プランA・B・Cを押すと、Gemini API（画像の編集）で同じ構図の完成イメージを作り、スライダーで見比べる
- STEP 3：読み込んだ図面（DXF）から作った3Dを回して見る
- STEP 4：選んだプランのA4提案書を印刷・PDF化

GeminiのAPIキーは画面の「設定」から入力し、その端末のブラウザにだけ保存します（このリポジトリには含みません）。three.js（MITライセンス）とSheetJS（Apache-2.0ライセンス）を `reform/lib/` に同梱しています。会社名・商品・価格はすべて架空です。
